# What AtlasGuard needs

| Need | Required? | Cost | Why |
|---|---|---|---|
| Python 3.11+ | yes | free | runs everything |
| Claude API credit (console.anthropic.com > Billing > Add funds) | for the real AI only | pay-as-you-go, start small | the agent plans and chooses tools. Demo mode (AG_MOCK=1) needs nothing |
| Internet | optional | free | live exchange rates; offline snapshot is used otherwise |
| Screen recorder (OBS or Windows Game Bar) | yes | free | the demo video |

No paid database, server or hosting is needed. Everything runs on one laptop.
